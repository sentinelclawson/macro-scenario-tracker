# macro-scenario-tracker

Weekly odds on five macro scenarios for rates, oil and stocks through 2028, re-scored every Monday.

Live: https://macro-scenario-tracker.netlify.app

The whole site is `index.html` (no build step). `CLAUDE.md` has the data schema, scoring rules and editing rules. `tools/tracker.py` validates and updates the data.

Scenario estimates, not investment advice.
